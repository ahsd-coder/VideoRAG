Question: How does the instructor differentiate between a 'buy limit' order and a 'buy stop' order?

### Differentiation Between 'Buy Limit' Order and 'Buy Stop' Order

In the retrieved information, the instructor differentiates between a 'buy limit' order and a 'buy stop' order as follows:

#### Buy Limit Order
- **Definition**: A buy limit order is an instruction to the broker to buy at a price that is lower than the current market price.
- **Usage**: This order is placed when a trader believes the price will fall below a certain level before rising again. 
- **Example**: If the current trading price is 100, a buy limit order might be set at 98. The order will be executed only if the price drops to 98 or lower.

#### Buy Stop Order
- **Definition**: A buy stop order is an instruction to the broker to buy at a price that is higher than the current market price.
- **Usage**: This order is placed when a trader believes the price will rise above a certain level.
- **Example**: If the current trading price is 100, a buy stop order might be set at 102. The order will be executed only if the price rises to 102 or higher.
