### Synthesizing an AHP Model in SuperDecisions to Obtain Global Priorities for Alternatives

#### Step 1: Setting Up the Hierarchical Structure
1. **Creating Clusters and Nodes**:
   - Start by creating clusters for the goal, criteria, and alternatives within the SuperDecisions software.
   - Define the goal at the top level, followed by criteria that contribute to achieving the goal, and then the alternatives that are being evaluated.

#### Step 2: Pairwise Comparisons
2. **Inputting Preferences**:
   - Navigate to the pairwise comparison section to input preferences between criteria and alternatives.
   - Use the software interface to compare each criterion against others and each alternative against others with respect to each criterion.
   - Ensure consistency in these comparisons by checking the inconsistency ratio, which should be less than 10%.

#### Step 3: Entering Ratings
3. **Rating Alternatives**:
   - For each criterion, rate the alternatives based on a predefined scale.
   - Enter these ratings into the software to reflect how each alternative performs against each criterion.

#### Step 4: Synthesizing the Model
4. **Computing Priorities**:
   - Access the computation menu to synthesize the entire model.
   - Click on the "Synthesize Whole Model" option to generate the global priorities for each alternative.
   - This step integrates all the pairwise comparisons and ratings to derive the overall priorities.

#### Step 5: Reviewing and Finalizing
5. **Reviewing Results**:
   - Once the synthesis is complete, review the synthesized priorities displayed in the software.
   - Check if the priorities align with expected outcomes or expert opinions.
   - Adjust ratings or comparisons if necessary to improve accuracy.

#### Example Process in SuperDecisions
- **Opening a Sample Model**:
  - Open a sample model from the Help menu under Sample Models, such as "Car Selection - AHP model".
  - Follow the instructions provided in the software to navigate through the setup process.

- **Navigating Through the Interface**:
  - Use the "Design" tab to set up the hierarchical structure.
  - Utilize the "Judgments" tab to input pairwise comparisons.
  - Switch to the "Ratings" tab to enter ratings for each alternative under each criterion.

- **Executing Synthesis**:
  - Go to the "Computations" tab and select "Synthesize Whole Model".
  - The software will display the synthesized priorities for each alternative.

#### Summary
By following these steps, you can effectively use SuperDecisions to synthesize an AHP model and obtain global priorities for the alternatives being evaluated. This process ensures that the decision-making is systematic and based on thorough comparative analysis.
