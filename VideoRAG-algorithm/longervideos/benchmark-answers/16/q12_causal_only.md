### Process of Creating an AHP Hierarchy in SuperDecisions Software

Creating an Analytic Hierarchy Process (AHP) hierarchy in SuperDecisions involves several key steps:

#### Step 1: Define the Goal
- **Action**: Start by specifying the overarching goal of your decision-making process.
- **Example**: For a car selection model, the goal could be "Buy the Best Car."

#### Step 2: Create Criteria Clusters
- **Action**: Establish the criteria that will be used to evaluate the alternatives.
- **Example**: Common criteria for car selection include "Prestige," "Price," "Miles per Gallon (MPG)," and "Comfort."

#### Step 3: Define Alternatives
- **Action**: List the specific alternatives that you wish to compare against each other.
- **Example**: For the car selection model, alternatives could be "Acura TL," "Toyota Camry," and "Honda Civic."

#### Step 4: Set Up the Hierarchical Structure
- **Action**: Organize the goal, criteria, and alternatives in a hierarchical structure within the SuperDecisions software.
- **Video Demonstration**:
  - **Tutorials**: The tutorials showcase how to set up this structure by adding criteria and alternatives to the hierarchy. For example, in the "CarSelection" model, the goal is connected to criteria, and each criterion is linked to the alternatives.
  - **Interface Navigation**: Use the software’s interface to navigate through different tabs and options, such as "Information Panel," "Model Structure," and "Cluster."

#### Step 5: Input Judgments
- **Action**: Enter judgments to compare the criteria and alternatives against each other.
- **Methods**:
  - **Pairwise Comparison**: Compare each criterion against another using a scale (e.g., 1-9).
  - **Rating Scale**: Rate each alternative against a criterion using a defined scale.
- **Video Demonstration**:
  - **Pairwise Comparison**: The tutorials illustrate how to perform pairwise comparisons by selecting nodes and entering judgments.
  - **Rating Scale**: Examples show how to define and use rating scales for evaluating alternatives.

#### Step 6: Compute Results
- **Action**: Use the software to compute the priorities for each criterion and alternative.
- **Process**:
  - **Synthesize Command**: Apply the "synthesize" command to calculate the overall priorities.
  - **View Results**: Check the results in the "Priorities" or "Results" tab to see the final rankings.

#### Step 7: Review and Refine
- **Action**: Review the results and refine the model if necessary.
- **Considerations**:
  - **Consistency**: Ensure the judgments are consistent.
  - **Sensitivity Analysis**: Conduct sensitivity analysis to validate the robustness of the model.

#### Example Workflow
1. **Title Screen**: Begin with the SuperDecisions software and select "Tutorial 01: Building a hierarchical pairwise comparison model."
2. **Hierarchy Diagram**: Visualize the three-level hierarchy, including the goal, criteria, and alternatives.
3. **Input Data**: Input the judgments for each criterion and alternative.
4. **Compute Priorities**: Use the "synthesize" command to compute the final priorities.
5. **Review Results**: Examine the synthesized priorities to determine the best alternative.

By following these steps, you can effectively create an AHP hierarchy in SuperDecisions to support your decision-making process.
