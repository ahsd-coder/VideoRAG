Question: How to establish connections between different elements in an AHP hierarchy within SuperDecisions?

### Establishing Connections Between Elements in an AHP Hierarchy Using SuperDecisions

To establish connections between different elements in an AHP (Analytic Hierarchy Process) hierarchy within SuperDecisions, follow these steps:

#### Step 1: Open the SuperDecisions Interface
Start by opening the SuperDecisions software and navigate to the appropriate module or file where your AHP hierarchy is stored. For instance, you might open a sample model or a previously created model.

#### Step 2: Identify Your Elements
Identify the elements you wish to connect. These elements can be criteria, sub-criteria, or alternatives. Ensure that each element is properly defined and placed within the hierarchy. For example, if you are evaluating car models, you might have criteria such as "Prestige," "Price," "MPG," and "Comfort," and alternatives like "Acura TL," "Toyota Camry," and "Honda Civic."

#### Step 3: Access the Connection Options
Navigate to the section in the SuperDecisions interface where you can make connections. Typically, this involves selecting options from the menu such as "Design," "Clusters," "Node Connections," or similar. The specific terminology may vary depending on the version and layout of the software.

#### Step 4: Connect Criteria and Alternatives
To connect criteria and alternatives, you can follow these steps:
- **Select Criteria**: Choose the criteria nodes you want to connect. For example, select "Prestige," "Price," "MPG," and "Comfort."
- **Select Alternatives**: Choose the alternatives you want to connect to these criteria. For example, select "Acura TL," "Toyota Camry," and "Honda Civic."
- **Enable Connection Mode**: Use the "Connection Mode" option to enable connecting nodes. This may involve clicking a button or selecting an option from a dropdown menu.
- **Make Connections**: Click on the criteria nodes and drag to connect them with the alternative nodes. Alternatively, you can use the "Node Connections" feature to manually select and connect nodes.

#### Step 5: Verify Connections
After making the connections, verify them to ensure they are correctly established. You can do this by checking the connections visually on the screen or by using the "Check Connections" feature provided by the software. The software may highlight successful connections with red borders or similar indicators.

#### Step 6: Enter Judgments
Once the connections are verified, proceed to enter judgments for the pairwise comparisons. This involves assigning values to indicate the relative importance of one element over another. For example, you might determine that "Prestige" is more important than "Price" for a specific alternative.

#### Step 7: Save and Synthesize Results
Finally, save your work and synthesize the results to obtain the priorities and weightages for each element in the hierarchy. This process involves using the "Synthesize" command to calculate the final priorities based on the judgments entered.

### Example Workflow

Here's a brief example of how you might establish connections in SuperDecisions:

1. **Open the Software**: Launch SuperDecisions and open the "Car Selection" model.
2. **Navigate to Connections**: Go to the "Design" menu and select "Clusters" to define your criteria and alternatives.
3. **Connect Nodes**:
   - Select the criteria nodes: "Prestige," "Price," "MPG," and "Comfort."
   - Select the alternative nodes: "Acura TL," "Toyota Camry," and "Honda Civic."
   - Enable connection mode and connect each alternative node to the criteria nodes.
4. **Verify Connections**: Check that the connections are properly highlighted and confirmed.
5. **Enter Judgments**: Use the "Judgments" tab to enter pairwise comparisons and judgments.
6. **Synthesize Results**: Use the "Compute" option to synthesize the results and obtain the final priorities.

By following these steps, you can effectively establish and manage connections between different elements in an AHP hierarchy within SuperDecisions, facilitating a structured and informed decision-making process.
