Question: How can sub-criteria be incorporated into the AHP hierarchy using Super Decisions software?

### Incorporating Sub-Criteria into the AHP Hierarchy Using Super Decisions Software

The process of incorporating sub-criteria into the Analytic Hierarchy Process (AHP) hierarchy using Super Decisions software involves several steps:

1. **Creating Clusters**:
   - Begin by creating a main cluster for your primary criteria.
   - Add sub-clusters within the main cluster to represent sub-criteria. For example, if the main criterion is "Working Environment," sub-criteria could include "Office Space" and "Team Dynamics."

2. **Defining Criteria and Sub-Criteria**:
   - Define your main criteria and sub-criteria clearly. For instance, in a job selection scenario, main criteria might include "Salary," "Research Opportunities," and "Growth Prospects," with sub-criteria nested under these main categories.

3. **Setting Up Hierarchical Structure**:
   - Organize your hierarchy in a structured manner within the Super Decisions interface. Use the software's tools to create a clear hierarchical tree where each criterion branches into its sub-criteria.

4. **Adding Alternatives**:
   - List your alternatives (e.g., different job positions or companies) and connect them to the appropriate criteria and sub-criteria. For example, if evaluating job positions, each position should be connected to the relevant criteria and sub-criteria.

5. **Entering Judgments**:
   - Input judgments for each criterion and sub-criterion. Use the software's judgment modes (e.g., questionnaire, direct entry) to assign relative importance values between criteria and sub-criteria.

6. **Synthesizing Results**:
   - Once all judgments are entered, synthesize the results within the software to obtain the overall priorities for each alternative based on the hierarchical structure.

#### Example Scenario: Job Selection

Consider a scenario where you're selecting the best job among three companies (Company A, Company B, and Company C) based on criteria such as Salary, Research Opportunities, and Growth Prospects. Each criterion may have sub-criteria:

- **Salary**: Base Salary, Bonus Potential
- **Research Opportunities**: Availability of Grants, Library Facilities
- **Growth Prospects**: Career Advancement, Training Programs

To incorporate these sub-criteria into the AHP hierarchy:

1. **Create Main Criteria Clusters**:
   - Create a cluster for "Salary" and add sub-clusters for "Base Salary" and "Bonus Potential."
   - Repeat for "Research Opportunities" with sub-clusters for "Grant Availability" and "Library Facilities."
   - Similarly, create a cluster for "Growth Prospects" with sub-clusters for "Career Advancement" and "Training Programs."

2. **Connect Alternatives**:
   - Connect each company (Alternative) to the relevant criteria and sub-criteria. Ensure that the hierarchy reflects the relationship between the main criteria and sub-criteria accurately.

3. **Input Judgments**:
   - Enter judgments to reflect the relative importance of each sub-criterion within its parent criterion. For example, you might judge "Grant Availability" as more important than "Library Facilities" under "Research Opportunities."

4. **Review and Synthesize**:
   - Review all judgments to ensure consistency and accuracy. Use the software's synthesis function to derive the overall priorities for each company based on the combined criteria and sub-criteria.

By following these steps, you can effectively incorporate sub-criteria into the AHP hierarchy using Super Decisions software, enabling a more nuanced and detailed decision-making process.
