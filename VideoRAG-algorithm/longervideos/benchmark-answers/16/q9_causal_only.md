Question: In SuperDecisions software, what steps are involved in performing sensitivity analysis for an AHP model?

### Steps Involved in Performing Sensitivity Analysis for an AHP Model Using SuperDecisions Software

To perform sensitivity analysis for an Analytic Hierarchy Process (AHP) model using SuperDecisions software, follow these steps:

1. **Load a Sample Model**:
   - Open a sample model using the `Help` menu, as shown in the video tutorial titled "SuperDecisions V3.2 Tutorial 02: AHP Sensitivity Analysis."
   - Load a pre-existing model, such as the "Car Selection - AHP model," to begin the analysis.

2. **Navigate to Sensitivity Analysis**:
   - Access the `Computations` menu and select `AHP Sensitivity` to initiate the sensitivity analysis process.
   - Alternatively, you can use the `Node Sensitivity` feature under `Computations` for more detailed sensitivity analysis.

3. **Set Up Independent and Dependent Variables**:
   - Edit the independent variable to specify the criterion whose sensitivity you want to study.
   - Ensure the dependent variable is correctly set up to reflect the changes in priority due to variations in the independent variable.

4. **Perform Pairwise Comparisons**:
   - Navigate to the `Judgments Tab` to make pairwise comparisons between criteria.
   - Select the goal node and perform the necessary comparisons to establish priorities among criteria.

5. **Evaluate Second-Level Subcriteria**:
   - Change nodes to compare second-level subcriteria within the AHP model.
   - Enter judgments for all clusters to ensure meticulous assessment of each criterion's performance relative to its goals.

6. **Conduct Graphical Sensitivity Analysis**:
   - Use the graphical sensitivity feature to visualize how the priorities of alternatives change as the priority of a criterion varies.
   - Highlight intersection points where specific criteria, such as "comfort," significantly influence the choice between alternatives like Toyota Camry and Honda Civic.

7. **Dynamic Sensitivity Analysis**:
   - After completing the initial sensitivity analysis, proceed to dynamic sensitivity analysis.
   - Access this feature through the `Computations` menu and select `Node Sensitivity`.
   - Configure the independent variable and observe how changes in criterion weights affect the ranking of alternatives.

8. **Review and Interpret Results**:
   - Examine the sensitivity graph and summary results to understand how different criteria affect the decision-making process.
   - Identify critical points where small changes in criterion weights lead to significant shifts in alternative rankings.

By following these steps, you can effectively use SuperDecisions to perform sensitivity analysis on your AHP models and gain insights into the robustness of your decision-making framework.
