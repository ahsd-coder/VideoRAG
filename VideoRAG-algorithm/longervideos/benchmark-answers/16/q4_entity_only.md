Question: How can the global priorities of alternatives be calculated in AHP using Super Decisions?

### Calculating Global Priorities of Alternatives Using AHP in Super Decisions

#### Step-by-Step Process:

1. **Setup the Model:**
   - Begin by setting up your decision-making model in Super Decisions. Define the goal node and create clusters for criteria and sub-criteria. For example, you might have clusters for "Criteria" and "Alternatives."
   - Add nodes under these clusters, such as "Sales," "Research," "Growth," and "Loyalty" as criteria, and "Alternative A," "Alternative B," and "Alternative C" as alternatives.

2. **Pairwise Comparisons:**
   - Perform pairwise comparisons for each criterion against the alternatives. This involves assigning relative weights to the alternatives based on their performance against each criterion. 
   - Use the software's interface to enter judgments, which can be done through a ratings model or directly via pairwise comparisons.

3. **Synthesize Local Priorities:**
   - After entering all pairwise comparisons, the software will compute local priorities for each alternative under each criterion. This step involves synthesizing the local priorities within each cluster.
   - Navigate to the "Computations" tab to initiate the synthesis process. Select the "Synthesize" option to generate local priorities for the alternatives.

4. **Compute Global Priorities:**
   - Once local priorities are computed, the next step is to calculate the global priorities. This involves synthesizing the entire model to derive the overall priorities of the alternatives.
   - Go back to the "Computations" tab and select the "Synthesize Whole Model" option. This will produce the global priorities for all alternatives.

5. **Review Results:**
   - After synthesizing the whole model, review the results displayed in the software. The global priorities will be listed for each alternative, reflecting their overall ranking based on the defined criteria.
   - Ensure the consistency ratio is acceptable to validate the reliability of the results.

#### Example Workflow:

- **Initial Setup:**
  - Open Super Decisions and navigate to the "Design" tab to create a new model.
  - Define a goal node and add clusters for criteria and alternatives.
  
- **Entering Judgments:**
  - Move to the "Rating" or "Comparison" tab to input judgments for each criterion.
  - Utilize the software's interface to assign values or make pairwise comparisons for each alternative.

- **Local Synthesis:**
  - Click on the "Computations" tab and select "Synthesize" to compute local priorities.
  - Review the local priorities generated for each alternative under each criterion.

- **Global Synthesis:**
  - Again, go to the "Computations" tab and select "Synthesize Whole Model."
  - Observe the global priorities for all alternatives, which indicate their overall ranking.

- **Validation:**
  - Check the consistency ratio to ensure the judgments are consistent and reliable.
  - If needed, adjust the judgments and recompute until the consistency ratio meets acceptable standards.

#### Additional Tips:

- **Consistency Checks:** Always perform consistency checks to ensure the judgments are reliable.
- **Export Results:** Save the model and export the results for further analysis or reporting.
- **Iterative Adjustments:** Be prepared to iteratively adjust judgments and recompute priorities to refine the decision-making process.

By following these steps, you can effectively calculate the global priorities of alternatives using the Analytic Hierarchy Process (AHP) in Super Decisions, ensuring a robust and informed decision-making process.
