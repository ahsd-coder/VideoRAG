### Process of Creating an AHP Hierarchy in SuperDecisions Software

Creating an AHP (Analytic Hierarchy Process) hierarchy in SuperDecisions involves defining the goal, criteria, and alternatives in a structured manner. Here’s a detailed explanation of the process:

#### Step 1: Define the Goal
- **Purpose**: The goal represents the overarching objective of your decision-making process.
- **Action**:
  - Open the SuperDecisions software.
  - Choose a template or create a new project.
  - Name your goal and provide a brief description.
  
#### Step 2: Create Criteria
- **Purpose**: Criteria are the factors that influence the decision and help in evaluating alternatives.
- **Action**:
  - Navigate to the "Design" section within SuperDecisions.
  - Add a new cluster named "Criteria".
  - Input the criteria names, such as "Prestige", "Price", "Miles per Gallon (MPG)", and "Comfort".
  - Provide descriptions for each criterion if necessary.

#### Step 3: Define Alternatives
- **Purpose**: Alternatives are the options you are comparing against each other.
- **Action**:
  - Add a new cluster named "Alternatives".
  - List the alternatives, such as "Acura TL", "Toyota Camry", and "Honda Civic".
  - Assign descriptions or details for each alternative if needed.

#### Step 4: Organize Hierarchically
- **Purpose**: Ensure a clear hierarchical structure by linking the goal, criteria, and alternatives.
- **Action**:
  - Connect the goal cluster to the criteria cluster.
  - Link each criterion to the respective alternatives.
  - Use the "Connect" feature in SuperDecisions to establish these relationships.

#### Step 5: Enter Judgments and Prioritize
- **Purpose**: Evaluate how each alternative performs against each criterion.
- **Action**:
  - Go to the "Judgments" section.
  - For each criterion, compare the alternatives against each other.
  - Enter judgments using the pairwise comparison method, rating how one alternative compares to another based on the specific criterion.
  - Save the judgments to apply them to the model.

#### Step 6: Synthesize Results
- **Purpose**: Calculate the overall priorities for each alternative based on the criteria.
- **Action**:
  - Access the "Compute" section.
  - Use the "Synthesize" function to generate the synthesized priorities.
  - Review the results, which will provide the overall ranking of alternatives based on the defined criteria.

### Additional Features and Tips

- **Rating Scales**: Define rating scales for criteria to standardize the evaluation process.
- **Consistency Check**: Verify the consistency of judgments to ensure reliable results.
- **Visualization Tools**: Utilize graphical representations to visualize the hierarchy and results.
- **Sensitivity Analysis**: Conduct sensitivity analysis to understand how changes in judgments affect the final priorities.

By following these steps, you can effectively create an AHP hierarchy in SuperDecisions, aiding in structured and informed decision-making processes.
