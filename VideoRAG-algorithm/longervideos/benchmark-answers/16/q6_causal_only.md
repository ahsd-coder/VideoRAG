Question: How can sub-criteria be incorporated into the AHP hierarchy using Super Decisions software?

### Incorporating Sub-Criteria into the AHP Hierarchy Using Super Decisions Software

#### Step-by-Step Guide

1. **Creating the Main Criteria:**
   - Start by defining the main criteria in your AHP hierarchy. These are the broad categories that encompass your decision-making process. For example, if you're evaluating different job offers, criteria might include salary, research opportunities, growth prospects, working environment, location, and reputation.

2. **Adding Sub-Criteria:**
   - Once the main criteria are established, you can introduce sub-criteria within each criterion. Sub-criteria provide a more granular breakdown of the main criteria. For instance, under "Working Environment," sub-criteria could include "Grant Availability" and "Library Facilities."

3. **Setting Up the Hierarchy:**
   - Use the Super Decisions software to build the hierarchy. Begin by creating a "Goal" cluster at the top level. Below the goal, add clusters for each main criterion. Then, add sub-clusters for each sub-criterion within the main criteria clusters.
   
   **Example:**
   - **Goal:** Buy the Best Car
     - **Criteria:**
       - **Prestige**
         - **Sub-criteria:**
           - Brand Recognition
           - Luxury Features
       - **Price**
         - **Sub-criteria:**
           - Base Cost
           - Additional Options Cost

4. **Inputting Data:**
   - Populate the hierarchy with the relevant nodes and connections. Ensure that each sub-criterion is properly connected to its parent criterion.
   - Input judgments for the comparisons between sub-criteria and their respective criteria. This involves assigning weights or importance levels to each sub-criterion relative to its parent criterion.

5. **Making Pairwise Comparisons:**
   - Navigate to the "Judgments" section within the software to begin making pairwise comparisons. Select the goal node and proceed to compare all criteria and sub-criteria accordingly.
   - Use the provided scales (e.g., 1-9) to rate the relative importance of each sub-criterion within its parent criterion.

6. **Synthesizing Results:**
   - After completing the pairwise comparisons, synthesize the judgments to calculate the priorities. This process involves computing the weights of each sub-criterion and criterion based on the input judgments.
   - Review the synthesized priorities to ensure consistency and accuracy. Adjust as necessary to refine the hierarchy.

#### Example Workflow

- **Video Tutorials:**
  - **Creating Hierarchies:**
    - Watch tutorials that demonstrate how to create hierarchies within Super Decisions. For example, a video might show how to set up a three-level hierarchy for selecting the best car, with criteria like prestige, price, and driving performance, and sub-criteria under each.
  - **Pairwise Comparisons:**
    - Follow tutorials that guide you through making pairwise comparisons between sub-criteria and their parent criteria. These tutorials often include step-by-step instructions on how to use the judgment area within the software.
  
- **Software Interface:**
  - **Clusters and Nodes:**
    - Use the software’s interface to create and manage clusters and nodes. For instance, create a cluster for “Goal,” another for “Criteria,” and sub-clusters for each sub-criterion.
  - **Rating Scales:**
    - Define rating scales for each criterion and sub-criterion. The software allows you to load existing scales or create new ones.

#### Conclusion

Incorporating sub-criteria into the AHP hierarchy using Super Decisions software involves a systematic approach of defining main criteria, adding sub-criteria, setting up the hierarchy, inputting judgments, and synthesizing results. By following these steps and leveraging the software’s features, you can effectively manage complex decision-making processes with multiple layers of criteria and sub-criteria.
