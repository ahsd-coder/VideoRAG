Question: How are ratings and intensities used in the absolute measurement process of AHP?

### Overview of Absolute Measurement in AHP Using Ratings Mode

The Analytic Hierarchy Process (AHP) utilizes the absolute measurement process to evaluate and prioritize alternatives based on predefined criteria. This process is often demonstrated using software like SuperDecisions, which offers a ratings mode to facilitate the implementation of absolute measurement. Here's how ratings and intensities are used:

#### Step-by-Step Process:

1. **Define Criteria and Alternatives:**
   - Start by identifying the criteria and alternatives that need to be evaluated. For example, in an MBA admission scenario, criteria might include Admission Test Results (ATR), Cumulative Grade Point Average (CGPA), Work Experience (WE), Letter of Recommendation (LOR), and Extra Activities (EA).

2. **Create a Ratings Model:**
   - Convert an AHP pairwise comparison model into a ratings model. This involves adding criteria and alternatives to the model and defining rating scales for each criterion.

3. **Rating Scales:**
   - Define rating scales for each criterion. These scales can be customized or reused from existing scales. For instance, criteria like "Prestige" and "Price" may use different rating scales depending on their nature.

4. **Evaluate Alternatives:**
   - Evaluate each alternative against the criteria using the defined rating scales. This involves assigning numerical values to each alternative for each criterion.

5. **Intensities and Priorities:**
   - Intensities represent the relative importance or weight of each criterion. These intensities are derived from pairwise comparisons or can be manually set. 
   - Priorities are the normalized values of intensities, indicating the proportionate contribution of each criterion to the overall decision.

6. **Pairwise Comparisons:**
   - Perform pairwise comparisons between criteria and alternatives to refine the ratings and intensities. This ensures consistency and accuracy in the evaluation process.

7. **Synthesize Results:**
   - Use the software to synthesize the results, generating a final ranking of alternatives based on the combined effect of all criteria.

#### Practical Examples:

- **MBA Admission Example:**
  - Criteria: ATR, CGPA, WE, LOR, EA
  - Alternatives: Candidates labeled as Candidate 1 through Candidate n
  - Ratings: Numerical values assigned to each candidate for each criterion
  - Intensities: Weights assigned to each criterion based on their relative importance
  - Priorities: Normalized intensities indicating the proportional contribution of each criterion

- **Car Selection Example:**
  - Criteria: Price, Quality, Safety, Comfort, and Driving Performance
  - Alternatives: Different car models
  - Ratings: Evaluations of each car model based on the criteria
  - Intensities: Importance levels of each criterion
  - Priorities: Final weighted scores for each car model

#### Software Interface and Features:

- **SuperDecisions Software:**
  - Provides a structured interface for defining criteria, adding alternatives, and inputting ratings.
  - Features include options to load and save rating scales, compare scale items, and synthesize results.
  - Tools for managing priorities, viewing inconsistencies, and exporting data.

#### Benefits of Absolute Measurement:

- **Efficiency:** Reduces the need for extensive pairwise comparisons, making it feasible to evaluate a larger number of alternatives.
- **Consistency:** Ensures that evaluations are consistent and aligned with predefined criteria.
- **Flexibility:** Allows for customization of rating scales and criteria, adapting to specific decision-making contexts.

By following these steps and leveraging the capabilities of software like SuperDecisions, decision-makers can effectively apply the absolute measurement process in AHP to derive meaningful insights and make well-informed decisions.
