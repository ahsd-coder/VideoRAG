Question: How are ratings and intensities used in the absolute measurement process of AHP?

### Overview of Ratings and Intensities in AHP

In the Analytic Hierarchy Process (AHP), the absolute measurement process using ratings and intensities plays a crucial role in decision-making. This process enables evaluators to assign numerical values to alternatives based on specific criteria, facilitating a more nuanced and detailed assessment.

#### Step-by-Step Process

1. **Defining Criteria and Alternatives**:
   - The process begins with identifying the criteria and alternatives that need to be evaluated. For instance, in the context of MBA admissions, criteria such as ATR (Admission Test Results), CGPA (Cumulative Grade Point Average), WE (Work Experience), LOR (Letter of Recommendation), and EA (Extra Activities) are defined. Each criterion represents a factor influencing the decision.

2. **Creating Rating Scales**:
   - Rating scales are established for each criterion to measure the performance of alternatives. These scales can be customized based on the context, such as Excellent, Good, Average, Poor, and Very Poor. The software often provides options to load existing scales or create new ones.

3. **Assigning Ratings**:
   - Evaluators then assign ratings to each alternative based on the predefined criteria. This step avoids pairwise comparisons and instead relies on absolute judgments. For example, a candidate might receive an 'Excellent' rating for their CGPA and a 'Good' rating for their WE.

4. **Entering Judgments**:
   - The ratings are entered into the software interface, which may involve filling out tables or matrices. Each alternative is rated against each criterion, allowing for a comprehensive evaluation.

5. **Synthesizing Results**:
   - After entering the ratings, the software synthesizes the data to produce priorities and total scores for each alternative. This synthesis helps in ranking the alternatives based on their overall performance across all criteria.

6. **Using Solver for Optimization**:
   - In cases where resource allocation is needed, the optimized priorities from the AHP model can be exported to Excel Solver. This tool helps in making decisions that maximize the total performance score given the available resources.

#### Practical Examples and Tools

- **Software Interface**:
  - The SuperDecisions software is commonly used for implementing the absolute measurement process in AHP. It offers features such as rating tables, scale management, and computation tools that streamline the evaluation process.
  
- **Rating Tables**:
  - Rating tables are used to input judgments for each alternative under each criterion. For instance, a table might include columns for 'Alternatives,' 'Prestige,' 'Driving Performance,' 'Space,' and 'Price,' with corresponding numerical values or descriptive ratings.

- **Solver Integration**:
  - For resource allocation problems, the synthesized priorities from the AHP model can be imported into Excel Solver. This integration allows for advanced optimization techniques, enabling users to allocate resources efficiently based on the priorities derived from the AHP process.

#### Key Considerations

- **Objective Judgments**:
  - When assigning ratings, evaluators must maintain objectivity and avoid comparing alternatives directly. Instead, judgments should be made based on an ideal standard for each criterion.

- **Customization**:
  - Custom rating scales can be created to suit specific contexts, enhancing the accuracy and relevance of the evaluation process.

- **Efficiency**:
  - Using ratings instead of pairwise comparisons significantly reduces the time and complexity involved in the decision-making process, especially when dealing with a large number of alternatives.

By leveraging the absolute measurement process in AHP, decision-makers can achieve a more systematic and efficient evaluation of alternatives, ultimately leading to better-informed decisions.
