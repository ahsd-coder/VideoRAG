### Process of Synthesizing an AHP Model in SuperDecisions

The process of synthesizing an Analytic Hierarchy Process (AHP) model in SuperDecisions to obtain global priorities for alternatives involves several key steps:

1. **Creating the Hierarchical Structure**:
   - Begin by setting up the hierarchical structure of your decision-making model. Typically, this includes a goal node at the top, criteria nodes in the middle, and alternatives at the bottom. For example, in a car selection model, the goal could be "Buy the Best Car," criteria could include "Prestige," "Price," and "MPG," and alternatives could be "Acura TL," "Toyota Camry," and "Honda Civic."

2. **Entering Judgments**:
   - After structuring the hierarchy, enter judgments for each comparison between criteria and alternatives. These judgments are often done using a pairwise comparison matrix, where you assess the relative importance or preference of one element over another.

3. **Normalization and Idealization**:
   - Normalize the data to ensure that each column sums to 1. This is achieved by dividing each value by the sum of the column. Next, find the idealized column by dividing each normalized value by the maximum value in its respective column. This step helps in creating a standardized comparison.

4. **Synthesizing the Model**:
   - Navigate to the synthesis options within the software. In SuperDecisions, this can typically be found under the "Computations" menu. Select the option to synthesize the entire model. This process combines the judgments entered into a coherent set of priorities for each level of the hierarchy.

5. **Viewing Global Priorities**:
   - Once the model is synthesized, you can view the global priorities for the alternatives. These priorities represent the overall ranking of each alternative based on the criteria and the goal. In SuperDecisions, the synthesized priorities are displayed in a table, often showing values under columns such as "Ideals" and "Normals," indicating the normalized and idealized scores.

6. **Interpreting Results**:
   - Interpret the results to understand the ranking of alternatives. For instance, if the synthesized priorities show that "Acura TL" has the highest value, it indicates that it is the preferred alternative based on the criteria defined in the model.

#### Example Steps in SuperDecisions

- **Step 1**: Open the model in SuperDecisions and navigate to the "Computations" menu.
- **Step 2**: Select the "Synthesize the whole model" option.
- **Step 3**: Review the synthesized priorities, which will be displayed in a table format.
- **Step 4**: Compare the priorities of different alternatives to determine the best choice.

By following these steps, you can effectively use SuperDecisions to synthesize an AHP model and derive meaningful global priorities for the alternatives in your decision-making process.
