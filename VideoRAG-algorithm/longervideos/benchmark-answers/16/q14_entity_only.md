Question: What are pairwise comparisons in AHP, and how are they conducted in SuperDecisions software?

### Pairwise Comparisons in AHP and Their Conduct in SuperDecisions Software

**Pairwise Comparisons in AHP:**

Pairwise comparisons in the Analytic Hierarchy Process (AHP) are a method used to quantify subjective judgments by comparing criteria or alternatives in pairs. This technique helps in determining the relative importance of each criterion or alternative in relation to a goal or other criteria. Users assign numerical values to these comparisons based on predefined scales, often ranging from 1 (equal importance) to 9 (extremely more important).

**Conducting Pairwise Comparisons in SuperDecisions Software:**

1. **Setting Up Clusters and Nodes:**
   - Users begin by setting up clusters for criteria and alternatives within the SuperDecisions software. Typically, there are three main clusters: Criteria, Alternatives, and Sub-criteria Clusters.
   - For example, in a tutorial video, users create a cluster named "3Alternatives" to organize criteria and subsequently arrange these clusters within the Network workspace.

2. **Creating Nodes:**
   - After setting up the clusters, users create nodes within each cluster to represent components. For instance, a goal node labeled "goal" is added at the bottom of the goal cluster.
   - The software interface facilitates this process with clear instructions and visual elements such as toolbars and navigation tabs.

3. **Entering Judgments:**
   - Once the nodes are created, users enter judgments for each criterion under different alternatives. These judgments are relative to an ideal state rather than comparing one alternative directly to another.
   - For example, users rate the prestige of a car as "above average" and emphasize the importance of keeping the ideal car in mind rather than comparing alternatives directly.

4. **Using Judgment Modes:**
   - SuperDecisions offers various modes for entering judgments, such as questionnaire mode, where users select a scale from 1 to 9 to indicate the preference or importance.
   - Users can also use direct entry mode to input tangible values directly or employ verbal mode for preference setting through drag-and-drop interactions.

5. **Synthesizing Results:**
   - After entering all judgments, users can synthesize the results to obtain a final output. This involves computing the overall priorities for the analyzed network, which is visually represented in formats such as bar charts.
   - For instance, in a tutorial, users synthesize judgments to see their final result based on the weighted sum of criteria.

6. **Addressing Consistency:**
   - SuperDecisions checks the consistency of the judgments entered by users. If the inconsistency ratio is above a threshold (often 0.1), users are prompted to revise their judgments.
   - Users can access the inconsistency report within the software to identify and correct any discrepancies.

7. **Visual Representation:**
   - The software provides visual aids like tables and matrices to help users understand the pairwise comparisons better.
   - For example, users can see the pairwise comparison matrix for criteria, where nodes like "Salary" and "Research" are compared based on their importance.

By following these steps, users can effectively conduct pairwise comparisons in SuperDecisions, facilitating structured decision-making processes that involve multiple criteria and alternatives.
